# verβ1.1 — Sakura macOS (Unofficial)

非公式macOS移植版の更新βリリースです。Sakura Editor Organizationが提供・承認・
サポートする製品ではありません。Windows版は引き続き保留し、Mac版のみ公開します。

## ダウンロードとインストール

- 対象: macOS 26.0以降。ローカル確認環境はmacOS 26.4.1 / Apple Silicon。
- DMG: `Sakura-macOS-v1.1.0-beta.1-universal.dmg`
- arm64 / x86_64 Universal。Intel実機での動作は未検証です。
- DMGを開き、SakuraEditor.appをApplicationsへドラッグしてください。
- リリースに添付された`SHA256SUMS.txt`とダウンロードしたDMGのSHA-256を照合してください。

Developer ID署名・公証はありません。パッケージ内のアプリはアドホック署名で
リソースを封印しますが、Appleが開発者や安全性を認証したものではありません。
macOSが起動を拒否する場合があります。出所を確認できない場合は実行せず、
Gatekeeperの一律無効化は行わないでください。重要な文書は別にバックアップしてください。

## β1.0からの主な変更

- 大容量文書の本文・表示行・検索用snapshotを共有ツリーで保持し、通常編集の全文コピーを削減。
- 前後検索・強調・一致件数・単一置換・全置換を非同期化。本文や選択、IME等の変更で古い結果を破棄。
- 検索とキャプチャ展開・追加色分けを共有本文の小さな読取り窓へ接続。
- 通常色分けの非同期・差分字句解析と表示範囲用トークン索引。
- Undo／Redoと各ペインの組版をworkerで準備。連打・中止・終了・通知中の再入・文書切替を保護。
- 対括弧ジャンプ（⌘]）。既定18ペアを非同期探索し、本文やUndo履歴を変更せず移動。
- ブックマーク位置補正の全文連結を除去。共有部分木と固定サイズ窓で比較。
- 復旧保存・削除を非同期化し、終了前に処理を排出。保存後の新しい文字コード／BOM設定を保護。
- CP932／EUC-JP判定の改善と曖昧警告。曖昧なGrep置換・キーワード取込みでは明示指定を要求。
- 選択範囲検索、検索条件共有、Grepの文字コード指定・除外・結果出力、限定的な`.kwd`交換。
- 論理行ジャンプ、行編集・文字変換、文書内ブックマーク、すべて保存、最近使った項目などの追加。

## 検証と制限

版番号更新前の統合チェックはDebug／Universal Release／ASan＋UBSanで各43/43成功、
ThreadSanitizerは変更に関係する15/15成功（リーク検証は含みません）。
公開用ソースは別途ビルド・テストし、リリース用DMGはGitHub Actionsから作成します。
これらは完全互換・無損失・実機IME・Intel実機動作を保証するものではありません。

本家Bregonig／Onigmoの正規表現、Windows設定、マクロ、プラグインの完全互換はありません。
MIGEMO、DIFF、タグジャンプ、入力補完、印刷、セッション／ブックマーク永続化などは未実装です。
常時括弧強調・独自pair設定UI、禁則・双方向組版・VoiceOverにも残件があります。
明示保存の符号化、起動時復旧読込み、表示設定変更、通常編集の大量履歴解放や
ブックマーク最悪時比較など、大容量文書の全操作が無停止になったわけではありません。

Grep置換の中止は保存済みファイルを戻しません。復旧データは本文と元パスを平文で保持します。
復旧の世代・容量制限はありますが、実際の電源断を含む保証試験は未完了です。
実装・制約・ライセンスはREADMEと同梱文書を参照してください。

公開ソースはMac版の限定スナップショットで、Windows用画像・配布ZIP・旧installer・
サブモジュール・上流全履歴を含めません。β1.0のタグと配布物は変更しません。
