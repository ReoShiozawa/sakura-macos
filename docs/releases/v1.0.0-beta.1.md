# verβ1.0 — Sakura macOS (Unofficial)

サクラエディタの操作感をmacOSへ移植する、最初の非公式βリリースです。
Sakura Editor Organizationが提供・承認・サポートする製品ではありません。
Windows版は保留し、今回の公開対象はMac版のみとしています。

## ダウンロードとインストール

- 対象: macOS 26.0以降。確認環境はmacOS 26.4.1 / Apple Silicon。
- アプリ: Sakura-macOS-v1.0.0-beta.1-universal.dmg
- 構成: arm64 / x86_64 Universal。Intel実機の動作は未検証です。
- DMGを開き、SakuraEditor.appをApplicationsへドラッグしてください。
- SHA256SUMS.txtとダウンロードしたDMGのSHA-256を照合してください。

Developer ID署名・公証は行っていません。アドホック署名によるリソース封印のみで、
Appleが開発者や安全性を認証したアプリではありません。
macOSが起動を拒否する場合があります。出所を確認できない場合は実行しないでください。
Gatekeeperを一律に無効化しないでください。必要に応じてソースからビルドできます。

## 主な実装

- 日本語IME、複数文書、2ペイン分割、矩形選択、Undo / Redo。
- UTF-8 / UTF-16 / CP932 / EUC-JP / ISO-2022-JP、BOM・改行保持。
- 行番号、折返し、不可視文字、タイプ別設定、Windows版を参考にした配色・メニュー。
- Unicode検索、ICU正規表現の検索・置換、非同期Grep、候補確認後のファイル置換。
- 軽量な構文色分け、アウトライン、外部変更検知、未保存内容の復旧。
- 非公式版表示、独立したBundle ID、独自アイコン、同梱ライセンス文書。

## β版の注意

重要な文書は別の場所へバックアップしてから利用してください。
本家の完全互換品ではなく、未移植の機能があります。Windowsの設定・マクロ・
プラグインやBregonig / Onigmoの正規表現との完全互換はありません。
Grep置換の中止は保存済みファイルを戻しません。
復旧データには本文と元パスが平文で保存され、容量・世代管理は未完成です。
禁則・双方向組版・VoiceOver・巨大文書での性能にも制約があります。

公開ソースはMac版に必要なファイルだけのスナップショットです。
Windows用画像、配布ZIP、旧installer、サブモジュール、上流の全履歴は含めません。
上流のLICENSEと原著作者の帰属を保持し、追加コードはLICENSE.macosを適用します。
動作・互換性・法的な完全性・無損失を保証するものではありません。
詳細な制限・ビルド手順・権利表示はREADMEと同梱文書を参照してください。
